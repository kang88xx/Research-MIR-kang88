# 텔레그램 인기글 위젯 — 소스 리서치 메모 (2026-07)

> 대상: 홈 텔레그램 채널 위젯 (components/TelegramChannels.tsx) 고도화 검토
> 결론: **추가 비용 $0 조합**으로 시작 — Telemetr 웹 Pro(보유 중)는 채널 발굴용, 포스트 데이터는 텔레그램에서 직접.

## 확인된 사실

1. **Telemetr 웹 Pro($18~21/월, 보유 중)에는 API가 포함되지 않음.**
   웹 구독과 API 요금제는 완전 별도 상품 (API는 @telemetrio_api_bot 통해 별도 구매).
2. **Telemetr API는 기능적으로는 충분** — `GET /v1/messages/channel` 하나로 본문·조회수·댓글수·전달수·리액션·message_id(→ t.me 링크)·광고글 필터(is_ad)까지 제공.
   - 단 "인기글 랭킹" 엔드포인트는 없음 → 채널별 24시간치 수집 후 조회수 직접 정렬 필요.
   - 비용: API-S $25/월(채널 50개·월 1,000콜 → 일 1회 갱신 한계), 시간 단위 갱신은 API-M $65/월.
3. **한국 커버리지 훌륭** — 한국×Cryptocurrencies 카탈로그 ~898개 채널 (업비트 공식·빗썸 알림·코인니스·블록미디어 등).
   웹사이트 스크레이핑은 ToS 위반 소지 + Cloudflare 차단으로 불가. 정식 경로는 API뿐.

## 권장 구성 (추가 비용 $0)

```
[Telemetr 웹 Pro — 보유 플랜 그대로]
  역할: 채널 발굴·큐레이션 (구독자·성장률·ER 기준 20~30개 선정, 월 1회 갱신)
        ↓ 채널 유저네임 리스트
[t.me/s 공개 프리뷰 폴링 — 무료, 실측 검증됨]
  역할: 10~30분 간격 → 본문·시각·조회수 → 조회수 증가속도 랭킹
        ↓ 상위 ~10개
[위젯 발행] 조회수 기준 (댓글·공유 수는 2단계)
```

- 댓글 수(💬)·공유 수(🔁)까지 필요해지면: Telethon 수집 계정(무료) 우선 검토.
  Telemetr API-S(+$25/월)는 일 1회 갱신 한계라 갱신 빈도 면에서 열세.
